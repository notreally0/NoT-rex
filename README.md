# Not-rex 

## What it is:

- ​It is a horror theme based Dino game similer to the Dinosaur game/T-rex runner but with colorfull 2d sprites and dark environment

## Whats Horror About it:

- The Dino is running in between a dark forest where Ghosts live!!
- There is a monster running behid the dino so if the dino trip over the obstacles the monster will catch it.
- horror background music
  
## How i made it:

- Free assets avalible on itch.io
- YouTube tutorials
- GDscript for scripting

## Whats Special:

- Colorfull Sprite
- 8-bit Bgm

## How to play

- Space bar: you just need to jump and avoid the obstacles

## Where to play 

- It is avalible on my Itch.io
- link: https://notreally0xd.itch.io/not-rex
